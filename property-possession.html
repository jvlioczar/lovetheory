Property 13 · Families that grip

Possession

How much I want them to be mine.

Sub-properties

  • Jealousy
  • Desired exclusivity (I want to be the only one)
  • Control (I want to know where, with whom)
  • Fear of loss
  • Comparison with others
  • Territoriality (my place, my group, my person)

Note

Jealousy is one name for at least seven mechanisms: property, fear of loss, comparison, scarcity, betrayal trauma, projection and cultural script. The mechanisms page opens each one.

Where it comes from

The same value can have different roots. For Possession, the most common:

  • Property (they're mine)
  • Fear of loss
  • Comparison (low self-worth)
  • Scarcity (fear of sharing time and attention)
  • Betrayal trauma
  • Projection (my own wish to stray)
  • Cultural script (jealousy proves love)

How it shows

Aggressive expression

Confrontation, prohibition, scenes

Peaceful expression

Withdrawal, stored hurt, unspoken rules

The trait doesn't change the value; it changes what the other sees. Peacefulness is not absence: it is the same value without noise.
